# 大脑调度工作台

把目标转成版本化计划，按本体输入、依赖和共享资源调度 Agent、DAG、TODO、Team，并在同一画布查看执行状态、输入输出、原生过程和产物证据。

## 产品约定

新建计划从右侧滑出 100% 画布；本体编辑内容、节点位置和视口在提交前缓存到浏览器，名称与一句话概述只在提交对话框填写。Action 必须绑定能力库实体，条件流转可将复测失败回退到修复并使用最新轮次输入，只有通过分支才能发布。

- **能力库**页签维护描述型能力：执行类型、一句话描述、输入/输出描述、工程输入条数、更新时间与执行目标绑定。简单表格 + 点击行打开「编辑能力」抽屉 + 「新建能力」按钮 + 按意图语义搜索与删除。Web 不提供能力成熟度（草稿/稳定）交互；成功/失败执行回执仍作为证据保存在服务端。通用 Agent、自定义 Agent、DAG/Team 定义、TODO 模板版本和规划产生的新能力构成计划步骤可选的能力目录，在计划编辑器目标下拉中出现。
- **固定计划**显式选择版本；**动态规划**参考能力快照及指定计划版本，一次产出完整计划，校验、保存后自动执行，无额外批准步骤。
- 每个计划版本不可覆盖，有 changelog、标签、置信等级和依据。草稿/稳定是发布成熟度，置信是另一个维度。稳定指针不会因一次执行成功自动改变。
- V1 的动态性发生在执行前。运行固定版本，不做运行中反思或重规划；条件、有限批量和汇合在计划内预先声明。改变计划需要新版本、新运行。
- 根运行固定所在节点；节点本地持久状态支持重启恢复，不承诺丢盘后跨节点接管。

## 交互路径

1. 大脑调度 → 工作台 → 开始新任务，填写目标、固定/动态模式、参考版本、根节点和初始输入。
2. 计划库可新建/编辑新版本、校验本体、对比版本、查看 changelog 和置信依据、标记稳定版本、执行指定历史版本。格式错误的 JSON 阻止保存。
3. 能力库页签点击行编辑能力、「新建能力」创建、按意图搜索和删除；没有成熟度标记或 JSON 展开行。
4. 运行页上方显示目标、固定版本、根运行阶段和激活次数；左侧步骤导航，中间执行/本体画布，右侧按实例检查概览、输入输出、原生执行过程和证据。
5. 点击步骤按稳定实例 ID 跟踪；批量实例按步骤分页。画布汇总整个计划，不依赖当前实例页推断完成度。
6. 缺失的必填输入显示持久请求。暂停停止新派发；取消等待已派发子执行的明确回执，不提前宣称副作用已停止。
7. 调度时间线可分页查询历史事件；刷新或重连从原子快照水位恢复。`?brain_run=<id>` 直接打开运行页。
8. 同一详情面板可查看四类执行的原生过程；DAG 原生页与嵌入详情保持一致。TODO 模板环境与工具保留在 TODO 管理的独立页签。

## 本体契约

完整示例见 [调度契约与运行协议](../../docs/brain-orchestration.md)。输入端口声明类型、语义、来源和必填性；来源是常量、用户输入、上游输出或批量项。获取外部数据由独立 action 完成，再通过输出端口连接。

- 数据类型为 JSON schema 的明确子集，拒绝未知字段；数组必须声明 items，对象可声明 properties/required，支持 enum、nullable、semantic。
- 输出绑定隐含依赖；`depends_on` 增加控制依赖。校验循环、缺失来源、类型/语义不兼容等。
- `when` 是预声明条件；`foreach` 是有限数组展开，要求唯一稳定项键；`collect` 等待完整展开集合，跳过条件未命中项，失败向下游传播。
- action 固定能力类型/目标/定义、agent 资源摘要、harness 配置、输出投影和有限重试策略。派发前选择资源摘要匹配节点，受理时再次核验并快照。
- 同名全局资源的读/读可并行，读/写和写/写互斥。资源占用无时间到期，明确完成/拒绝回执才能释放。
- 输出经类型校验后进入 `OutputEnvelope`；最终 deliverables 也需满足 schema 和可选 expected。自然语言验收标准由执行者遵循，需要强判断时应添加返回布尔结果的验证步骤。
