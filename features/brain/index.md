# 大脑调度工作台

计划画布配置显式层级中的里程碑：名称、目标、达成标准及每个里程碑挂载的 1–32 个能力。能力库在检查面板展示输入、输出与必填输入；画布编辑完成后，在提交表单填写计划名称、整体目标、工程输入和反思轮数，再校验并保存版本。浏览器草稿保留画布与表单内容。

同层能力执行形成屏障后，大脑评估里程碑状态，决定继续下一层或反思回退到先前层；回退开启新轮次，正常逐层推进不增加轮数。回退路径由运行决策确定，schema 6 计划不保存回退连线。计划最多 256 个里程碑、32 层、每层 32 个里程碑。运行页按轮次、层和激活查看调度理由、能力输入绑定、类型与独立执行 ID；通过 ID 复用现有 Agent、DAG、Team、Operator、TODO 和 Brain 执行面板查看明细。

新计划要求 schema_version 6。运行读取 `/api/brain/runs/:id/layered`，事件与定时轮询刷新；暂停、恢复、取消及阻塞后调整轮次预算使用运行命令。

历史激活保留当时的调度动作、理由与执行索引，独立展示当前执行状态；后续完成或回退不会覆盖派发依据。
