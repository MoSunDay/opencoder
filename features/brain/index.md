# 大脑调度工作台

计划画布以大容器表示里程碑层。每层必填名称、要做什么、目标和达成标准，容器内可放 1–32 个并行执行节点，每个节点只选择能力库中的一个泛化能力；名称与一句话任务说明来自能力库，不单独配置。画布和绑定选择框以“类型 · 能力自身名称”标识能力，保存及调度仍引用能力库的稳定 ID。相邻层的连线只展示正常前进顺序，无需配置回退线或决策条件。能力检查面板展示描述、输入、输出和必填参数。画布完成后在表单填写计划名称、整体目标、工程输入和轮次预算，再校验并保存不可变版本；浏览器草稿保留两部分内容。新计划从计划库创建，工作台展示运行记录。

大脑在同层节点全部终态后，结合各层能力说明和执行证据评估当前里程碑。达标后前进到紧邻下一层；需整改时可回到本层或任一已执行层，并说明原因。正常前进不增加轮次，回退或本层重试开启新轮次；每次激活有独立的执行 ID。嵌套子计划沿用父运行节点和固定计划版本。运行页主视图展示层级状态、调度控制和画布；右侧详情抽屉按轮次折叠，以表格列出该轮各层的能力执行状态和记录，调度理由及输入可继续展开。点击执行记录复用 Agent、DAG、Team、Operator、TODO 和 Brain 的执行面板按 ID 读取明细；Agent、Operator 和 Team 可在明细中向大脑提交引导。

新建计划与点击当前计划名称共用全屏画布及计划信息表单：新建保存首个版本，已有计划载入内容供修改，保存产生同一计划的下一版本。关闭后保留浏览器草稿；历史版本通过单独入口只读查看、比较和执行。

运行页的“查看详情”在右侧抽屉显示人工输入和事件记录；输入最多 4096 字节。运行页及托管执行详情中的人工输入通过累计容量校验后写入大脑事件并唤醒一次决策，超限返回 413 且不改变当前执行。本层仍有执行未结束时，大脑可即时引导本层运行中的 Agent/Operator；Team 在下一次成员发问时应用引导，同时记录下一步的调整意见，不能派发新层。下一次调度可据此调整 Agent、Operator、Team 等能力的任务输入。DAG 需要改图时先停止原运行，再提交新运行。生产激活复用 OpenCoder agent loop，每次事件只输出一个有限调度决策。

新计划与新运行使用 `schema_version: 7`，限制为 1–32 层、总共 1–256 个节点、每层 1–32 个节点。运行读取 `/api/brain/runs/:id/layered`，由事件与轮询刷新；暂停、恢复、取消和轮次预算调整使用运行命令。历史 schema 4/5/6 只读，编辑旧计划会创建 schema 7 新版本。

结构合法的计划还须通过完整证据容量检查。模型窗口读取执行节点的有效配置，默认 128000 tokens，并为输出预留 16384 tokens；决策正文与传输帧还分别受 1 MiB、2 MiB 限制。超限在启动前返回 413，用户须缩小计划或输入，或选择实际支持更大窗口的模型。已受理运行冻结容量，修改节点配置不会扩大其预算，也不靠省略成功证据继续执行。

无法解析的能力在目录中标记为不可用，画布禁止新挂载；引用它的计划返回具体错误，不影响其他能力。

能力库可配置必填输入、必填输出字段，和执行目标一起保存；新建能力使用默认 Agent 时也会保存绑定。输入字段在解析引用后检查，输出检查结果最外层字段；DAG 的最外层字段是步骤名称。缺失、null 或空白文本不满足要求，false、0 和空数组可以作为有效数据。必填字段不代替达成标准，也不定义完整的 JSON 类型约束。

能力库表格展示执行类型、一句话描述、更新时间和操作，搜索结果另显示距离。一句话描述限宽并显示省略号，完整内容在详情中保留；输入描述、输出描述和工程示例仅在详情表单中展示。窄屏表格内部可横向滚动。

大脑读取完整结构化结果，执行结束不等于任务通过。输入引用错误或输出缺失会携带原因回到大脑，供其重新绑定输入、重试或返回此前步骤。Coding → Test → 修复 → 再测试使用相同调度规则；不同执行之间须显式传递代码版本、补丁或产物，并依据对应版本的验证结果决定完成。叶子能力的决策结果最多 16 KiB，大文件和长报告使用产物引用。

运行只能调度计划中已绑定的能力；同层节点仍整层派发。重试和回退受轮次预算约束，默认 5 轮，可配置 1–32 轮；预算耗尽时明确阻塞，不把未验证的任务标为完成。新任务需要支持当前字段校验与完整结果传递的执行节点。
