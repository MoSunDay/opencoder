# 大脑调度工作台

计划画布以大容器表示里程碑层。每层配置名称、目标和达成标准，容器内可放 1–32 个并行执行节点，每个节点绑定能力库中的一个泛化能力；画布和绑定选择框以“类型 · 能力自身名称”标识能力，保存及调度仍引用能力库的稳定 ID。层间连线写明前进或回退条件。能力检查面板展示输入、输出和必填参数。画布完成后在表单填写计划名称、整体目标、工程输入和轮次预算，再校验并保存不可变版本；浏览器草稿保留两部分内容。新计划从计划库创建，工作台展示运行记录。

大脑在同层节点全部终态后评估当前里程碑，按已配置的出边决定下一层。正常前进不增加轮次，回退或本层重试开启新轮次；每次激活有独立的执行 ID。运行页按轮次和激活展示调度理由、能力输入、类型及 ID，点击执行项复用 Agent、DAG、Team、Operator、TODO 和 Brain 的执行面板按 ID 读取明细。

新计划与新运行使用 `schema_version: 7`，限制为 1–32 层、总共 1–256 个节点、每层 1–32 个节点。运行读取 `/api/brain/runs/:id/layered`，由事件与轮询刷新；暂停、恢复、取消和轮次预算调整使用运行命令。历史 schema 4/5/6 只读，编辑旧计划会创建 schema 7 新版本。

无法解析的能力在目录中标记为不可用，画布禁止新挂载；引用它的计划返回具体错误，不影响其他能力。「PC 问题诊断与修复」安装入口保留旧版本并幂等追加当前 schema 7 版本；线上为 `pc-issue@4`。
