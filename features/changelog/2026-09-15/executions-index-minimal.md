# 全部执行页收敛为只读浏览

## 背景

「Agent → 全部执行」承担执行记录检索和明细查看，不再承担新建执行或历史翻页入口。页面标题与“舰队全部执行记录与团队过滤”描述也会让列表区域重复表达同一语义。

## 变更

- 页面保留执行类型筛选、刷新、记录表格和明细抽屉。
- 移除“启动执行”和“加载更早的执行”按钮及其状态、游标和弹窗代码；列表固定读取当前 API 返回的一页并继续静默轮询。
- 将 topics 页面设为无页头页面，导航中的“全部执行”菜单项仍保留。
- 端到端验收脚本改为通过 API 创建测试执行，再从列表打开明细，避免依赖已移除的入口。

## 验证

- SPA Vitest：89 个测试文件、693 个测试全部通过。
- SPA production build 通过。
- `platform.js`、`t12_ui_verify.js`、`harness/codex.js` 通过 `node --check`。
