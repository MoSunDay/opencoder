# 首个 PC 问题实证计划

工作台接入文本和图片问题输入、五阶段 schema 5 计划及产品结论展示。全局理解、源码、预约 Windows 复现、抓包、隔离修改、jy-builder 构建和候选复测共享冻结输入与真实证据链。

新增鉴权图片及证据下载、前序输出校验、阶段子任务取消约束和便携候选包适配器。证据不足保留明确缺口；不会把流程结束或诊断包通过当作产品已修复。部署与契约见 [PC 问题计划](../../../docs/brain-pc-issue.md)。

阶段目标以提交真实评估报告为准。有效的受阻、无需执行或证据不足报告继续向前传递到最终结论，不要求为完成里程碑而宣称产品复现或修复成功；反思仍仅允许从复测返回修复。

- 实机验收发现模型会附加阶段小结；宿主提取唯一明确标记的 JSON 代码块，仍拒绝多块歧义及损坏格式，所有结构、证据哈希和跨阶段结论校验保持强制。

- PC 阶段直接装配宿主固定输入和完整权威前序结果，不再先解析随后必然覆盖的模型输入绑定；避免错误 JSON Pointer 造成阶段派发无限重试。
