# 大脑里程碑字段与手动连线

计划编辑改为由泛化能力提供并行节点名称和一句话任务说明，节点只需选择能力。里程碑新增必填的“要做什么”，与名称、目标、达成标准分别保存和校验。

选中里程碑后可选择下一层或已执行层添加连线，连线详情只编辑条件；选中连线后从画布工具栏删除。大脑仍按当前里程碑的出边和条件决定前进或回退，回退开启新轮次。内置 PC 问题计划安装会为缺少里程碑任务的旧 schema 7 版本追加新版。

运行视图缺少 schema 7 计划或层投影时显示明确的分层数据错误，不进入里程碑渲染。
