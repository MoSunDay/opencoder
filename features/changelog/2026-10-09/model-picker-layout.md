# 模型选择列表对齐

模型弹窗的单选项用 `display: block` 覆盖 antd 的默认布局，导致按钮与名称上下错位，长名称还会超出弹窗。

[modelModal.jsx](../../../crates/web/spa/src/modelModal.jsx) 改用 `Radio.Group` 的纵向排列，保留单选项自身布局，并允许名称在可用宽度内换行。
