# 输入停止时及时解除节点连接

控制通道的输入超时曾在每轮发送后重置，并在待入队帧存在时停用；旧连接可能一直保留，新连接被拒绝，节点就绪与接收、查询受到影响。输入现在独立使用原有 `STALE_MS=20000` 截止时间，仅实际读到有效输入才续期。超时走既有 detach 路径，保留冻结请求、执行归属和持久结果，不提高配额、不调整鉴权或知识库能力。

定向测试覆盖持续发送但无输入、满队列、健康心跳续期、帧顺序与交接写出、真实 WebSocket 断开后同代次重连并保留任务 owner/status；既有 handoff/report 测试验证迟到结果与代次边界。原实现的满队列回归已失败并保留，新实现通过。

79 与本节点的 b1b 取消确认均成功；79 完整执行观察和双端公网 900 秒已通过。71 原执行观察有两次失败（终态晚 81.61 秒、另一次 POST 接收超时），保留原证据；它们不能被之前公网 PASS 或本次定向测试替代。正式发布后分别复验持续执行、重连和取消。
