# 维护升级保留不可启动的历史记录

历史 Runtime 注册仍在、发布记录和数据目录已缺失时，维护预检明确拒绝继续。仅在管理员已持久禁用对应服务、进程已停止、数据路径不存在且不是软链接、休眠快照属于本节点且任务全部终态时，才将该记录列为不可启动的历史记录。

切换清单保存这些注册记录原文；不删除注册、执行归属、休眠快照或鉴权数据，也不新建缺失的数据目录。可运行的历史 Runtime 继续完整升级。缺少证据、仍有任务或等待用户输入的会话均阻止发布。

定向验证：`test_unavailable.py` 覆盖既有数据和未禁用服务拒绝、活动任务及等待输入会话拒绝、注册和快照保留、重新开放入口不创建缺失目录；`test_engine.py` 和 `test_runtimes.py` 验证维护切换、程序恢复及原有 Runtime 保留。
