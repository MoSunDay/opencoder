# 项目工作台

项目分类提供 Overview 和 Tag 两个菜单。Overview 顶部直接显示项目、专项、TODO 三个表格页签，不重复展示页面标题和工作台介绍；Tag 独立管理标签。数据列可按文本、Tag、人员、数值或日期筛选；项目归档和 TODO 看板状态还可按状态筛选；保存刷新和关闭抽屉后重新打开会保留视图中的筛选条件。

项目、专项、TODO 可分别设置一位负责人和多位关注人，只选择现有 OpenCoder 用户；三层独立，不继承，移动归属也不改变人员。负责人可为空，关注人自动去重；删除用户后清理其关系，同名用户重新创建不会继承旧关系。人员列表只展示用户名，修改沿用原有项目写权限。界面支持设置、清空与筛选，读取失败显示错误和重试入口。人员关系为后续通知提供数据，当前没有通知投递。

项目和专项可维护“当前概述”，列表支持查看和筛选，详情展示完整 Markdown 及概述更新时间。概述由用户或授权的 Codex / Operator 按需整理：专项读取全部 TODO 进展及其历史执行证据，输出关键进展、核心工作、剩余卡点；项目在更新各专项后汇总全部所属专项。节点离线、读取失败或专项概述缺失会明确提示，不据此推断任务完成。命令与写入方式见 [当前概述用法](../../docs/project-summaries.md)。

概述更新时间由服务器在正文写入时生成；只修改负责人、名称、项目归档或说明不刷新该时间。空字符串可清空概述，未传正文保持原值；概述不自动修改 TODO 看板，也不启动定时总结。概述保留最近 10 个版本（含当前），项目、专项列表、项目内专项表格及详情均可查看概述历史，ctl 也可查看内容、时间及回滚来源。清空也留记录，回滚新增版本；写入或历史保存失败时整笔撤回，已清理的版本不能回滚。

点击项目打开右侧详情抽屉，列出全部专项及进度条。专项可通过左侧手柄拖拽或键盘调整顺序，刷新后保持；筛选隐藏项保留相对顺序，保存失败恢复，其他人已修改列表或顺序时提示刷新后重试。专项页签中名称列与所属项目列等宽，长名称换行完整展示。专项完成度按已完成 TODO 数量除以总数计算；项目进度按全部专项的 TODO 总数计算，空列表显示 0%。点击专项打开全宽右侧 TODO 看板，用户可在待整理、待办、进行中、已完成四列之间拖动卡片，并调整列内顺序。筛选后拖动会保留隐藏卡片的顺序，保存失败恢复原状态；看板状态不随执行状态自动变化。

Tag 在独立菜单中统一管理，表格显示名称、归属类型、所属项目和所属专项；可新建、编辑名称及归属、确认删除。归属类型支持全局、项目、专项；全局无需选择具体归属，所有项目、专项及未归属 TODO 均可使用，也可归属独立专项。切换至项目或专项类型后须重新选择具体归属；同一归属内名称不能重复，保存失败保留草稿。首次读取失败显示错误和重试入口；viewer 可查看标签，不能新建、修改或删除。

一个 TODO 可选择多个 Tag。专项继承所属项目和全局的 Tag，同名时按专项、项目、全局的顺序选择；未归属 TODO 仅可使用全局 Tag。修改名称或归属时保留 Tag ID，已选关联按保存后的名称重新匹配；删除定义时使用原名称寻找同名可用 Tag，无法匹配则解除关联。未选择标签的 TODO 不会自动添加标签。按 Tag 分组时，同一 TODO 可显示在多个分组，状态变化会同步到所有卡片，统计只计一次。

专项可不关联项目，TODO 可不关联专项；TODO 页签包含全部任务和未归属任务。删除项目会保留专项和 TODO；有 TODO 的专项须先解除挂载才可删除。项目里程碑入口已移除，存量里程碑下的 TODO 转为未归属任务，历史执行记录保留。

TODO 新建与编辑表单按任务内容、归属与状态、负责人和关注人分区，编辑时另列执行设置与指派记录。字段带可见标签，宽屏并排、手机单列，说明输入框随内容增高，多标签和关注人可换行。新建与保存按钮固定在抽屉底部，失败提示在操作区展示并保留草稿，提交中禁用字段；空标题校验定位到标题输入框。

用户保存 TODO 后，从能力库选择具体的 Agent、Operator、Team、DAG、TODO 工作流或保存的 Brain 计划版本，再填写任务和命名参数。TODO 标题和说明预填为可修改的输入，保存 TODO 本身不触发派发。提交和回复丢失后的重试使用同一个执行 ID；变更输入或能力须发起新执行。

一个 TODO 可关联多次执行，也可直接关联 operator 当前正在使用的执行 ID。关联只记录能力与执行引用；会话、工具记录和产物归执行节点持有。用户打开时读取当前结论，节点离线明确报错，不显示缓存成功；DAG 结果从步骤明细读取。删除 TODO 或解除关联保留原执行，执行完成不自动改变看板列。

全宽右侧 TODO 抽屉展示执行列表与按需读取的结论，宽度随视口变化。多个 operator 可分别执行同一 TODO；多人也可打开同一执行 ID，共享上下文并通过原生明细提交引导。人工输入在回复未确认时保持原输入 ID。项目不设置独占领取锁，也不为 TODO 新建额外会话或调度循环。

CLI 提供 `project people`、`project todos links/attach/detach/dispatch` 和 `exec result`，与 Web 共用 Server API；独立 Web 的旧项目 API 不提供控制台执行索引。创建和修改的人员字段为 `owner_user_name`、`follower_user_names`；PATCH 不传则保留，分别传 `null`、`[]` 清空。非法用户使整次对象和 Tag 修改回滚。

- 专项没有自身状态，列表与创建、编辑不提供状态选择；专项进度由所属 TODO 的看板状态计算。API 不返回状态，并拒绝含 `status` 的专项创建和修改。
