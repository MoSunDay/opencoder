# 项目工作台

工作台保留项目、专项、TODO 三个页签，均以表格展示并支持增删改查。数据列可按文本、状态、Tag、数值或日期筛选；保存刷新和关闭抽屉后重新打开会保留视图中的筛选条件。

点击项目打开右侧详情抽屉，列出全部专项及进度条。专项完成度按已完成 TODO 数量除以总数计算；项目进度按全部专项的 TODO 总数计算，空列表显示 0%。点击专项打开右侧 TODO 看板，用户可在待整理、待办、进行中、已完成四列之间拖动卡片，并调整列内顺序。筛选后拖动会保留隐藏卡片的顺序，保存失败恢复原状态；看板状态不随执行状态自动变化。

Tag 可在项目或专项下创建、改名和删除，一个 TODO 可选择多个 Tag。专项继承所属项目的 Tag，同名时使用专项定义；修改归属或删除定义后，同名可用 Tag 会接替，否则清除失效关联。按 Tag 分组时，同一 TODO 可显示在多个分组，状态变化会同步到所有卡片，统计只计一次。

专项可不关联项目，TODO 可不关联专项；TODO 页签包含全部任务和未归属任务。删除项目会保留专项和 TODO；有 TODO 的专项须先解除挂载才可删除。项目里程碑入口已移除，存量里程碑下的 TODO 转为未归属任务，历史执行记录保留。

用户保存 TODO 后，从能力库选择具体的 Agent、Operator、Team、DAG、TODO 工作流或保存的 Brain 计划版本，再填写任务和命名参数。TODO 标题和说明预填为可修改的输入，保存 TODO 本身不触发派发。提交和回复丢失后的重试使用同一个执行 ID；变更输入或能力须发起新执行。

一个 TODO 可关联多次执行，也可直接关联 operator 当前正在使用的执行 ID。关联只记录能力与执行引用；会话、工具记录和产物归执行节点持有。用户打开时读取当前结论，节点离线明确报错，不显示缓存成功；DAG 结果从步骤明细读取。删除 TODO 或解除关联保留原执行，执行完成不自动改变看板列。

右侧 TODO 抽屉展示执行列表与按需读取的结论，窄屏时宽度不超出视口。多个 operator 可分别执行同一 TODO；多人也可打开同一执行 ID，共享上下文并通过原生明细提交引导。人工输入在回复未确认时保持原输入 ID。项目不设置独占领取锁，也不为 TODO 新建额外会话或调度循环。

CLI 提供 `project todos links/attach/detach/dispatch` 和 `exec result`，与 Web 共用 Server API；独立 Web 的旧项目 API 不提供控制台执行索引。项目页不提供旧的专属计划、执行或回放操作。
