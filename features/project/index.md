# 项目工作台

项目可汇集里程碑和专项，两者同级且均可独立存在。TODO 可挂在里程碑或专项下，也可留在未分组列表。删除项目不会删除分组或 TODO；有 TODO 的里程碑或专项须先解除挂载才可删除。

TODO 由用户维护标题、说明、归属与状态。一个 TODO 可以关联多个执行，关联只保存执行 ID；页面按执行索引展示类型、名称、状态和 ID。用户可粘贴已有执行 ID，也可从 Agent、Team、DAG 工作流、TODO 工作流或大脑的原生界面发起，发起成功后自动关联。无法关联不存在的执行或这些能力之外的执行类型；关联失败保留 ID 供重试。执行关联不自动改变 TODO 状态。

执行详情复用各能力的 WebUI，不在项目页维护另一套记录与提交语义。项目页不提供旧的专属计划、执行或回放操作。
