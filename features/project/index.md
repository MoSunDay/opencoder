# 项目工作台

项目可汇集里程碑和专项，两者同级且均可独立存在。TODO 可挂在里程碑或专项下，也可留在未分组列表。删除项目不会删除分组或 TODO；有 TODO 的里程碑或专项须先解除挂载才可删除。

TODO 在待整理、待办、进行中、已完成四列看板中展示。用户可拖动卡片跨列或在列内排序；筛选时暂不拖动，排序与列状态会保存。TODO 的标题、说明和分组由用户维护，看板列不随执行状态自动变化。

用户保存 TODO 后，可进入 Agent、Operator、Team、DAG 工作流、TODO 工作流或 Brain 的原生界面发起执行；TODO 标题和说明预填为可修改的输入，不从说明文字中自动解析能力或派发。一个 TODO 可关联多次执行，每条记录保留类型、名称、执行 ID、状态和独立结论；也可粘贴已有执行 ID 关联，关联失败时保留 ID 供重试。执行产物由后台读取并回写；没有结论、失败和取消分别显示，只有非空结论才显示“结论已回写”，不覆盖 TODO 自身的计划和看板列。

右侧 TODO 抽屉展示指派历史与最新结论，窄屏时宽度不超出视口；可打开对应能力的原生执行明细，运行中的 Team 可从详情提交引导。执行关联与详情由 Server 控制台提供；独立 Web 的旧项目 API 不提供控制台执行索引。项目页不提供旧的专属计划、执行或回放操作。
