# UI 验收约定

## 范围和入口

- 保留当前视觉风格。完整范围是 `crates/web/spa/src/nav.js` 注册的页面，以及连接 Server 的 TUI；不能只检查正在修改的页面。
- `scripts/acceptance/ui/scope.js` 记录每个页面对应的功能验收。增加或移除导航页时同步修改验收范围；未覆盖的页面使验收失败。
- 全站入口：`node scripts/acceptance/ui/main.js --bin-dir <独立二进制目录> --rootfs <配套镜像> --output <新的证据目录>`。
- `--resume` 只能复用范围及构建产物摘要相同的成功记录；失败保留原日志并重跑，SPA 漂移检查始终重跑。`--brain-test <同批构建的测试可执行文件>` 可避免共享 Cargo 目录重建版本不一致，仍须通过测试内的原生镜像版本检查。
- 前置条件：当前 SPA 已构建，二进制构建信息一致，SPA 摘要与 Server 一致，镜像中的 runner 与二进制目录一致；使用项目安装的 Playwright 浏览器，或通过已有 `CHROME_PATH` 指定浏览器。
- TUI 验收需要 `pyte`；Rust 浏览器用例需要 Cargo。测试只使用临时凭据、数据库、目录和私有挂载空间，不操作生产服务或已有认证数据。

## 必须检查的链路

| 页面或终端 | 完整操作 |
| --- | --- |
| 项目 | 项目、专项和 TODO 的创建编辑、关联、筛选、Tag、排序和执行结果 |
| 全部执行 | 受理、状态更新、明细、日志、产物和节点离线错误 |
| DAG 工作流 | 定义编辑、版本选择、派发、动态实例、日志产物与固定资源快照 |
| 二进制资源 | ELF 上传、追加版本、下载摘要、确认切换当前版本、确认删除、保留已受理任务的版本 |
| 定时任务 | 创建编辑、参数数组、启停、确认手动触发、历史跳转到原执行、删除后保留历史 |
| Team 组队 | 创建编辑成员、启动、真实讨论和最终结论 |
| Agent | 选节点才能发送、首次创建、后续消息继续同一个执行 |
| Agent 配置 | 资源配置与 Agent、二进制、工作区、Ontology 正文四类 NFS 的实际状态和路径；停止导出须确认 |
| Ontology 五个页面 | 类型、属性与 Action 配置，实体正文与搜索，关系创建，图谱与保存切面，环境隔离及实际只读 NFS 挂载 |
| 节点列表 | 在线状态、维护入口、真实受理节点和离线提示 |
| 大脑调度 | 计划画布、并行能力执行、返回上层、子任务和执行明细 |
| TUI | Agent/任务选择、Server 消息展示、继续会话、恢复、切回本地和退出不打断远端任务 |

## 状态与显示

- 请求失败不能显示为“空列表”“已停止”或默认配置。显示实际错误和重试入口，保留用户填写的内容。
- 身份确认完成前不展示管理页面；失败允许重试，401 返回登录入口。
- 切换资源、页面或执行后，旧请求不得覆盖当前内容；关闭组件时取消未完成的读取。
- 提交中阻止重复操作；删除、停止导出和切换资源当前版本需要确认。
- DAG 容器、工作目录和固定版本来自已保存的运行资料，不查询当前资源池来推测历史；执行方式遵循 `04-dag-execution-contract.md`。

## 验收和提交

- 在 1920、1280、768、390 像素宽度遍历所有注册页面、页内标签和主要弹窗，保存截图和测量结果。表格与分类标签容器内部可以横向滚动，页面和外层布局不能溢出。
- 截图遍历不替代功能验收。真实功能使用独立 Server、执行节点和 runc；仅模型回答与单独的显示、错误分支可使用确定性测试数据。
- 验收入口检查遗漏的页面、未知测试请求、浏览器异常、命令退出码和构建摘要；失败不能生成通过回执。
- 变更同时通过 SPA 全量测试、Rust 全量测试、格式检查、Clippy 和发布脚本回归。原生 DAG 与平滑切换继续执行真实进程验收及 15 分钟观察。
- 平滑切换的受理延迟与调度间隙沿用最大值 30 秒门槛，不使用 1 秒或 P95 替代。
- 所有事项通过后才可以按用户授权提交本地代码；开发镜像验收不表示已部署生产，也不替代正式发布包的验收。
